# FXTV App Launcher
A C# WinForms launcher for games and applications featuring user authentication, SQLite integration, and a scalable architecture for future networking projects.

This project is part of my journey learning desktop application development, networking, databases, and software engineering. It will eventually become the launcher for multiple personal projects, including multiplayer games and networking experiments.
